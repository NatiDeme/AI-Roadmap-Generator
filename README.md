# AI Roadmap Generator
This is a simple AI roadmap generator designed to assist users on their learning journey.

[![Video](https://cdn.loom.com/sessions/thumbnails/18408e9c420846c9b0f1aae11886761f-bbe7a73f03c69795-full-play.gif#t=0.1)](https://www.loom.com/share/18408e9c420846c9b0f1aae11886761f)

# Tech stack
- Nx - for managing the monorepo structure
- Express -  for backend API
- React - for frontend UI
- Tanstack / ReactQuery - for data fetching, and fetching state management
- Tailwind CSS - for styling

# Getting started

To get a local copy up and running, follow these simple steps:

- clone the repo [Repo Link](https://github.com/NatiDeme/AI-Roadmap-Generator

```sh
npm install
```

```sh
npx nx dev api
npx nx dev web
```

- You should see your backend running on port 3333 and frontend running on port 8080
